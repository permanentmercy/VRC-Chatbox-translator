# VRC Chatbox Translator

这是一个为 VRChat 设计的聊天框与双语字幕辅助工具。基于 WinUI 3 开发，主要用于在游戏内展示语音转写、本地大模型实时翻译、打字同步以及角色头顶常驻文本。

## 主要功能

### 语音转写
- Windows 11 实时字幕联动：直接捕获系统内置 LiveCaptions 的文本流，不额外占用 GPU 显存，对游戏帧率几乎没有影响。
- 本地 Whisper 引擎：内置离线 Whisper 识别，支持 tiny/base 等模型，支持使用 CUDA 加速或 CPU 推理。
- 自动断句：识别出的长句会按标点与停顿自动切分，避免一次性堆积过多文字。

### 本地 AI 翻译
- 支持连接本地运行的 Ollama 服务进行翻译，可自定义模型名称、接口地址和翻译提示词。
- 提供“识别/翻译直接发送到 VRChat”选项。开启后，说话或翻译结束时直接发送到游戏内头顶气泡，不会篡改或覆盖软件当前输入框里的未发送草稿，发送时不会触发打字动画。

### 游戏内聊天与打字交互
- 实时打字预览：打字时可实时同步到头顶气泡，回车后正式发送并播放提示音。
- 输入法保护：在中文拼音输入选词阶段不发送未确定的拼音字母，避免在游戏内穿帮。
- 频率限制保底：严格遵守 VRChat 的 OSC 限流要求（单包间隔不低于 110ms），避免丢包。
- 头顶常驻文本：可在头顶循环保持一段自定义文字（例如个人状态、挂机提示等）。自己主动说话或发送新消息时会优先展示新内容，气泡淡出后再自动恢复常驻文本。

### 透明悬浮窗
- 桌面沉浸式半透明窗口，未被卡片覆盖的空白区域支持鼠标硬件级穿透点击底层的游戏或桌面。
- 支持按住 Alt+鼠标左键或鼠标中键拖拽移动位置。
- 支持全局快捷键（默认 Ctrl+Shift+Z）随时呼出与隐藏。

### 外部调用接口
- 内置简易 HTTP 服务与 OSC Inbound 端口，支持第三方脚本或程序直接调用本工具向 VRChat 发送消息。

## 系统要求

- 操作系统：Windows 10 / 11 64位（若使用 Windows 原生实时字幕联动，需 Windows 11 22H2 或更高版本）。
- 运行环境：.NET 10.0 SDK 或运行时。
- VRChat 设置：游戏内圆盘菜单需开启 OSC 支持（Action Menu -> Options -> OSC -> Enabled）。
- Ollama（可选）：仅在使用本地 AI 翻译时需要安装并提前运行。

## 编译与运行

### 编译
```bash
git clone git@github.com:permanentmercy/VRC-Chatbox-translator.git
cd VRC-Chatbox-translator
dotnet build -c Release
```

### 独立发布 (Self-contained)
```bash
dotnet publish -c Release -r win-x64 --self-contained true -o ./publish
```
输出目录位于 `./publish`，包含完整运行时，可在未安装 .NET 环境的机器上直接运行 `VrcChatboxDemo.exe`。

## 常见说明

1. VRChat OSC 连接失败：
   - 确认 VRChat 游戏内 OSC 开关处于开启状态。
   - 默认发送端口为 9000，IP 为 127.0.0.1。如果修改过端口需保持两端一致。

2. Windows 11 实时字幕无反应：
   - 首次使用时需确保系统已经下载了对应的离线语言包。
   - 若要监听自己的麦克风声音，在系统自带实时字幕窗口的设置中勾选“包含麦克风音频”。

3. 快捷键冲突：
   - 可以在“快捷键设置”页面中根据个人习惯重新绑定全局唤醒与悬浮窗快捷键。
