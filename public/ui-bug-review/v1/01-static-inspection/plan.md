# UI 缺陷排查计划

## 版本与阶段

- 功能模块：UI 缺陷排查
- 版本：v1（只读静态排查）
- 阶段：01 静态检查
- 状态：已完成

## 范围

- 检查 WinUI 3 界面 XAML、页面代码后置、窗口交互与 UI 状态绑定。
- 只记录可由代码证据支持的 UI 缺陷；不审查服务层业务、网络、音频或其他非 UI 问题。
- 不修改应用源码，不运行测试。

## 执行步骤

1. 盘点窗口、页面、组件与样式资源。
2. 检查导航、控件状态、输入反馈、布局尺寸/缩放和窗口交互。
3. 将每项发现记录文件位置、复现条件、影响与证据；未能确认的线索标为待验证。
4. 更新本计划状态，并在 `result.md` 汇总结果与检查限制。
