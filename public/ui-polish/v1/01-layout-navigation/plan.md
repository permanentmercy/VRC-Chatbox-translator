# UI 布局与导航优化计划

## 版本与阶段

- 功能模块：UI 布局与导航
- 版本：v1（共享设置页布局与切换优化）
- 阶段：01 布局、提示文字与导航体验
- 状态：已完成

## 目标

1. 统一各设置子页面的内容宽度，减少切换时的横向跳动。
2. 窄内容视口时提供横向可达性，避免右侧设置被裁切。
3. 让主要设置卡片在统一内容列内完整呈现，调整超出列宽的固定列。
4. 删除重复或可能过期的快捷键说明，保留一处清晰的编辑指引。
5. 保持页面缓存以保留输入草稿和滚动位置，并统一页面切换行为。
6. 修正恢复默认导航顺序遗漏 TTS 的问题。

## 执行步骤

1. 复核现有页面宽度、固定列、快捷键描述和导航生命周期。
2. 建立共享设置页容器样式，统一基准宽度并允许窄视口横向滚动。
3. 将会超出基准宽度的固定布局调整到内容列范围内。
4. 精简快捷键说明，启用页面缓存并为 Frame 导航设置一致的无位移动画。
5. 修正默认导航顺序，检查 XAML/代码的交叉引用并构建项目。
6. 更新 `result.md` 与本计划状态，记录变更、验证和限制。

## 执行记录

- 将翻译、交互、TTS 设置分区的固定列调到 700 DIP 内容列可容纳的尺寸。
- 主聊天页及设置子页启用导航缓存；Frame 缓存 7 页，并对页面导航显式关闭位移过渡，减少切页时草稿/滚动状态丢失及横向闪动。
